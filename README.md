<a id="english"></a>

Free your mouse and fingers from repetitive trading.

Backstab The Trade is a Dalamud plugin that helps with repeated in-game gil and item trades.

## Features

### Gil Trade Mode

Enter the amount of gil you want to trade. The plugin builds a trade plan and helps process the trade.

### Item Manual Mode

Enter the quantity of items you want to trade. The plugin builds a trade plan from your inventory and helps process the trade.

### Gil to Item Trade Mode

Enter the gil value you want to pay. The plugin builds a trade plan using inventory items with a similar total value.

### Receiver Mode

Receiver Mode can automatically press `Trade` and confirm `Yes` while you are receiving a trade.

### Event Tracker

- Useful for debugging and testing
- Tracks the most recent 50 trade records

### Time Settings

Time Settings let you adjust delays to better match your game client, network, or testing needs.

## 日本語

Backstab The Trade は、ゲーム内でくり返し行うギル取引やアイテム取引を補助する Dalamud プラグインです。

### Gil Trade Mode

渡したいギルの金額を入力すると、プラグインが取引プランを作成し、取引を補助します。

### Item Manual Mode

渡したいアイテム数を入力すると、所持品から取引プランを作成し、取引を補助します。

支払いたいギル相当の金額を入力すると、その価値に近いアイテムで取引プランを作成します。

Receiver Mode は、受け取り側のときに `Trade` と確認ウィンドウの `Yes` を自動で押します。

### Event Tracker

- デバッグやテストに便利です
- 直近 50 件の取引記録を追跡します

### Time Settings

Time Settings では、ゲーム環境やネットワーク、テスト条件に合わせて待機時間を調整できます。
