Free your mouse and fingers from repetitive trading.

Backstab The Trade is a Dalamud plugin that helps with repeated in-game gil and item trades.

## Features

### Gil Trade Mode

Enter the amount of gil. The plugin builds a trade plan and helps process the trade.

### Item Manual Mode

Select items and enter the quantity. The plugin builds a trade plan from your inventory and helps process the trade.

### Gil to Item Mode

Enter the amount of gil. The plugin builds a trade plan using inventory items with a similar total value.

### Receiver Mode

Receiver Mode can automatically press `Trade` and confirm `Yes` while you are receiving a trade.

### Event Tracker

- Useful for debugging and testing
- Tracks the most recent 50 trade records

### Time Settings

Time Settings let you adjust delays to better match your game client, network, or testing needs.

## UI Language

Press the corresponding button to choose your UI language.

### Installation

1. Type `/xlsettings` in game.
2. Open the `Experimental` tab.
3. Copy `https://raw.githubusercontent.com/Ray-CR/BackstabTheTrade/main/pluginmaster.json`.
4. Paste it into the available repository input box.
5. Click the `+` button to add it to the list.
6. Click `Save and Close`.
7. Search for `Backstab The Trade` and install it.

## 機能紹介

Backstab The Trade は、ゲーム内でくり返し行うギル取引やアイテム取引を補助する Dalamud プラグインです。

### Gil Trade Mode

渡したいギルの金額を入力すると、プラグインが取引プランを作成し、取引を補助します。

### Item Manual Mode

アイテムを選び、渡したい数を入力すると、所持品から取引プランを作成し、取引を補助します。

### Gil to Item Mode

支払いたい金額を入力すると、その価値に近いアイテムで取引プランを作成します。

### Receiver Mode

Receiver Mode は、受け取り側のときに `Trade` と確認ウィンドウの `Yes` を自動で押します。

### Event Tracker

- デバッグやテストに便利です
- 直近 50 件の取引記録を追跡します

### Time Settings

Time Settings では、ゲーム環境やネットワーク、テスト条件に合わせて待機時間を調整できます。

## UI Language

対応するボタンを押して UI 言語を選択してください。

### Installation

1. ゲーム内で `/xlsettings` を入力します。
2. `Experimental` タブを開きます。
3. `https://raw.githubusercontent.com/Ray-CR/BackstabTheTrade/main/pluginmaster.json` をコピーします。
4. 利用可能な repository 入力欄に貼り付けます。
5. `+` を押して一覧に追加します。
6. `Save and Close` を押します。
7. `Backstab The Trade` を検索してインストールします。
